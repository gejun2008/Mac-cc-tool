# Copilot 评估报告套件

一个文件搞定:使用说明 + 两段提示词 + 两个模板。在工作电脑上打开本文件,
按顺序复制粘贴即可,不需要任何脚本。

> 红线:明细表和报告含语料内容,只能存内网,**不要提交进本仓库**。

## 使用说明(三步)

1. **出草稿**:每次取「一个文档 × 一个引擎」,把【提示词 A】+ 原文档关键页
   (截图或文字)+ 该引擎生成的 md,一起粘给 Copilot → 得到对照明细表草稿。
2. **人工核对**:逐格核对判定,改错、补备注。核对后另存为
   `明细/<引擎>-<文档名>.md`。**没核对过的表不能进下一步。**
3. **出报告**:把【提示词 B】+ 全部核对后的明细表粘给 Copilot →
   得到最终《评估报告.md》。通读一遍确认结论都能回指到明细表,定稿。

## 提示词 A —— 逐 case 对照(一次只做一个文档 × 一个引擎)

```text
你是文档解析评估员。下面给你两份材料:【原文档内容】和【某 OCR 引擎生成的 markdown】。
你的任务:逐项对照,只输出一张明细表,不写任何总结。

规则:
- 只依据我给的材料判断,材料里没有的不许推测。
- 每项判定只能是:✅ 完整 / ⚠️ 部分(备注写清缺什么)/ ❌ 失败 / N/A(该引擎无此能力)。
- 纯文本引擎(如 azure-read)在表格结构、公式、流程图维度一律记 N/A,不记 ❌。
- 证据列必须同时引用原文片段和输出片段,可截断但不许改写。
- 输出中发现原文没有的内容,判定记 ❌ 并在备注标「幻觉」。

逐项检查以下维度(原文档不含某维度的,跳过不填):
1 无边框表格:是否识别为表格;行列数与对齐是否一致;单元格内容是否完整
2 多重表头:合并单元格是否还原;展平后每个列名是否正确(逐列数,备注写 对/总数);表头与数据行边界
3 特殊字符:货币符号、千分位、括号负数、±、上下标、全角半角;原文的 | * _ 是否撑破 md 表格
4 图片内容:图片位置是否检出;图内文字是否提取;描述是否与图一致(不一致=幻觉)
5 LaTeX 公式:是否识别为公式;LaTeX 语法能否渲染;符号/上下标/分式与原式是否等价
6 流程图→mermaid:节点数与文字;连线关系与方向;分支条件文字;mermaid 语法能否渲染
7 通用:阅读顺序;标题层级;漏段/重复段;幻觉内容

输出表格式(每个维度一行或多行):
| case_id | 文档 | 类型 | 维度 | 引擎 | 判定 | 证据(原文 vs 输出) | 备注 |

文档名:<填>    文档类型:<word/ppt/pdf>    引擎:<azure-layout/mistral-ocr/azure-read>

【原文档内容】
<粘贴原文关键页文字,或附截图>

【引擎输出的 markdown】
<粘贴该引擎生成的 md>
```

## 提示词 B —— 汇总报告(全部明细表核对完之后)

```text
你是文档解析评估员。下面是若干份已经人工核对过的对照明细表,它们是唯一事实来源。
按我给的骨架生成最终评估报告,规则:
- 只允许汇总明细表里已有的判定,不许新增任何明细表之外的结论。
- 每条结论后面用 (case_id) 标注依据。
- 能力矩阵的格子取该维度下所有 case 的最差判定;N/A 照抄 N/A。
- 「失败模式清单」按 现象→复现文档→疑似原因→建议(自研/换引擎) 逐条写。

【报告骨架】
# OCR 能力评估报告
## 1. 结论(一页):能 quick resolve 的 / 必须自研的 / 各引擎一句话定位
## 2. 能力矩阵:行=7个维度,列=引擎×文档类型(word/ppt/pdf),格=✅/⚠️/❌/N/A
## 3. 分维度明细:每维度一节,判定 + 2-3 个并排证据(原文 vs 各引擎输出)
## 4. 失败模式清单
## 5. 附录:逐 case 明细表

【核对后的明细表】
<粘贴全部明细表>
```

## 明细表模板(空表,人工核对时用)

```markdown
| case_id | 文档 | 类型 | 维度 | 引擎 | 判定 | 证据(原文 vs 输出) | 备注 |
| ------- | ---- | ---- | ---- | ---- | ---- | ------------------- | ---- |
```

## 判定口径速查

- **✅ 完整**:结构与内容均与原文一致。
- **⚠️ 部分**:检出但结构或内容有缺,备注必须写清缺什么。
- **❌ 失败**:未检出、结构崩坏或出现幻觉(幻觉在备注单独标)。
- **N/A**:引擎无此能力(text 引擎的表格/公式/流程图),不算失败,不参与比分。
