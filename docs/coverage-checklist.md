# 文档解析问题覆盖清单

评估的对照清单。每次跑新引擎照着过一遍,避免整个类别被遗漏。

「已覆盖」指 [fix-plan.md](fix-plan.md) 六项修复计划中已列入的问题,序号对应该表。

## 覆盖情况

| 类别 | 已覆盖(对应序号) | 未覆盖的缺口 |
| --- | --- | --- |
| **表格结构** | #6 PDF 表格错位 | 无边框表检出、跨页表合并与误合并、嵌套表、单元格内换行撑破 md、纵向表头(转置表)、表题/单位行/脚注与表体失联、超宽表 |
| **公式与数字字符** | #2 公式、#3 字符噪声 | 行内公式漏检、数字精度静默截断、金融格式(括号负数、千分位、bp、货币符号、全半角)、公式编号丢失、表格单元格内的公式 |
| **图片与图形** | #5 图片漏检、#4 流程图 | chart → 数据还原、图片描述幻觉、图文位置关联、印章/水印/签名、截图型表格 |
| **版面与阅读顺序** | 无 | 阅读顺序(双栏 PDF、PPT 文本框)、标题层级还原、页眉页脚页码混入正文、脚注与引用点关联、目录、跨页段落续接 |
| **内容完整性** | #1 部分覆盖 | 整段/整页漏失、重复复读、输出截断、空输出、生成式引擎两次结果不一致 |
| **文档形态与格式** | 无 | xlsx、老二进制格式 .doc/.xls/.ppt、加密文档、修订痕迹与批注、隐藏行列/隐藏幻灯片、PPT 备注页、嵌入 OLE 对象 |
| **下游可用性** | 无(属能力建设,见下) | 表头展平、md 转义破坏、分块边界、页码与来源回链 |
| **工程与可复现** | 无 | 输出稳定性、模型版本漂移、页数与文件大小限制、成本与限流、时延 |

## 建议补入计划的缺口

现有六项覆盖的都是**引擎明确失败**的显性问题;下列缺口多为**看起来成功
但内容已错**的静默问题,或整个层面尚未进入视野。

| 优先 | 缺口 | 为什么重要 |
| --- | --- | --- |
| 1 | 数字精度与金融格式保真 | 完全静默。`0.10`→`0.1`、`(1,234)`→`1234`(负号丢失)、千分位被吃,输出看着正常,下游结果全错。金融场景严重性最高 |
| 2 | chart → 数据还原 | 立项目标之一,六项中缺失。原生 Office 的 chart 在 XML 中带缓存数值(`native_structure=full`),直读成本极低 |
| 3 | 阅读顺序 | 整个类别空白。双栏 PDF、PPT 文本框顺序错乱后一字不丢但语义全乱,同属静默失败 |
| 4 | xlsx 与老二进制格式 | 金融机构必有大量 Excel,当前工具链完全未覆盖;要么补,要么在能力边界中明确声明不支持 |
| 5 | 表格上下文关联 | 「单位:人民币百万元」、表题、脚注注 1/注 2 通常在表体之外,失联后数字即为废数据 |
| 6 | 输出截断与重复 | 生成式引擎(mistral-ocr、VLM)长文档典型失败;确定性引擎无此问题,易被忽略 |

## 分类说明

**表头展平不在「不支持项」清单中,不代表它不重要。** 它属于要自研的
**能力建设**,与六项**引擎缺陷修复**是两个清单。报告中应分开列示,
否则易被误读为表头问题已解决。
